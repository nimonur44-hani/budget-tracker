# SpendWise - Budget Tracker

## Project Description
SpendWise is an interactive budgeting application developed using HTML, CSS and JavaScript. It helps users manage monthly budgets, record expenses and monitor their remaining balance.

## Improvements Made in Week 6
- Added a monthly budget input form.
- Added an expense recording form.
- Added automatic balance calculations.
- Added budget status notifications.
- Added the ability to delete expenses.
- Updated dashboard information dynamically.

## JavaScript Concepts Used

### 1. Conditional Statements
If, else if and else statements check whether users are within budget or exceeding their budget.

### 2. Arrays
Arrays store multiple expense records, including expense names and amounts.

### 3. Loops
For loops calculate total expenses and display expense records.

### 4. DOM Manipulation
JavaScript uses getElementById(), textContent and createElement() to update dashboard information.

### 5. Event Listeners
addEventListener() handles form submissions and delete button clicks.
