# My Budget Tracker

## Project Description
My Budget Tracker is a simple web application designed to help users keep track of their income and expenses.

## Technologies Used
- HTML5 – Used to create the structure of the application.
- CSS3 – Used to style the application and improve its appearance.
- Google Fonts – Used to improve typography.

## Main Features
- Budget Tracker heading and logo.
- Expense entry form.
- Expense table displaying sample expenses.
- Budgeting tips section.
- Responsive design for smaller screens.

## CSS Improvements
- Applied a consistent green and white colour palette.
- Used Poppins and Inter Google Fonts.
- Styled input fields, buttons and tables.
- Added spacing, padding, margins, borders and shadows.
- Added hover and focus effects.
- Included responsive styling for smaller screens.

## Project Files
- `index.html` – Contains the structure of the Budget Tracker.
- `style.css` – Contains the visual design and styling.
- `README.md` – Explains the project and its components.

## Conclusion
This project demonstrates how CSS can improve the appearance, readability and usability of a web application.
