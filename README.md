
# SpendWise Dashboard

## 1. Project Description
SpendWise is a personal budget tracking dashboard designed to help users organize and monitor their finances. It provides a clean and responsive interface for viewing income, expenses, savings and financial categories.

## 2. Dashboard Features
- Sidebar navigation menu.
- Header with a welcome message.
- Three financial summary cards:
  - Total Balance
  - Total Income
  - Total Expenses
- Six financial category cards:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- Recent transactions table.
- Responsive mobile layout.
- Hover and keyboard focus animations.
- Automatic dark theme support.

## 3. Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties (Variables)
- CSS Media Queries

## 4. Project Structure

### index.html
Contains the structure of the SpendWise dashboard, including the sidebar, header, summary cards, expense categories and recent transactions.

### style.css
Controls the appearance and layout of the dashboard. It uses CSS Grid and Flexbox, custom properties, responsive media queries and card animations.

### README.md
Provides information about the project, its features and technologies.

## 5. Responsive Design
The dashboard uses a CSS media query at 768px to adapt to smaller screens. The mobile layout displays content in a single column.

The responsive layout was tested using Chrome DevTools Device Toolbar with an iPhone 16 device preview.

## 6. Dark Theme
The project supports automatic dark mode using the prefers-color-scheme media query and CSS custom properties.

## 7. How to Run the Project
1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
